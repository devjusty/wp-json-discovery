This directory is intentionally small. Use these files as the source of truth.

- `docs/product-roadmap.md`
  - Strategic roadmap and sequencing (quarter-scale priorities).
- `docs/product-redesign-brief.md`
  - Confirmed from-scratch product model, workflows, design principles, and redesign scope.
- `docs/scan-capabilities.md`
  - What the scanner and admin tools currently do, plus known gaps.
- `docs/scan-capability-inventory.md`
  - R0 classification and migration targets for investigator and admin capabilities.
- `docs/research/2026-09-09-r0-research-brief.md`
  - R0 repository observations, workflow hypotheses, evidence limits, and unresolved questions.
- `docs/superpowers/specs/2026-09-09-r0-contracts-design.md`
  - R0 shared-contract scope, validation flow, migration seams, and exit criteria.
- `docs/public-api-paths.md`
  - Reference list of public WordPress endpoints and integration notes.

Historical one-off implementation plans were consolidated into `docs/scan-capabilities.md` and removed to avoid drift.
