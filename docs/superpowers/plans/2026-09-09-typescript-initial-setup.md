# Initial TypeScript Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add TypeScript checking to both workspaces while keeping all existing JavaScript runnable and unchanged.

**Architecture:** Use one `tsconfig.json` per workspace because Vite browser code and Node ESM server code need different module settings. Both configs include existing JavaScript with `allowJs`, perform no output, and initially leave `checkJs` and `strict` disabled. New redesign code will use TypeScript; legacy files migrate only when touched.

**Tech Stack:** TypeScript, Vite, Node ESM, pnpm workspaces, React, Jest.

---

### Task 1: Add TypeScript dependencies

**Files:**
- Modify: `frontend/package.json`
- Modify: `server/package.json`
- Modify: `pnpm-lock.yaml` (generated by pnpm)

- [ ] **Step 1: Add TypeScript to frontend**


- [ ] **Step 2: Add TypeScript and server declarations**

Expected: server `devDependencies` contain TypeScript plus declarations for Node and currently used Express middleware dependencies.

- [ ] **Step 3: Confirm dependency installation**

```bash
pnpm install --lockfile-only
```

Expected: pnpm exits successfully and keeps the workspace lockfile internally consistent.

### Task 2: Configure frontend typechecking

**Files:**
- Create: `frontend/tsconfig.json`
- Modify: `frontend/package.json`

- [ ] **Step 1: Add frontend compiler configuration**

Create `frontend/tsconfig.json`:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "useDefineForClassFields": true,
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "allowImportingTsExtensions": false,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "jsx": "react-jsx",
    "allowJs": true,
    "checkJs": false,
    "strict": false,
    "noEmit": true,
    "skipLibCheck": true
  },
  "include": ["src"],
  "exclude": ["node_modules", "dist"]
}
```

- [ ] **Step 2: Add frontend typecheck script**

Add this entry to `frontend/package.json` scripts:

```json
"typecheck": "tsc -p tsconfig.json"
```

Do not change existing frontend scripts.

- [ ] **Step 3: Run frontend typecheck**

Run:

```bash
pnpm --filter frontend run typecheck
```

Expected: TypeScript exits 0 without generating files or requiring source conversion.

### Task 3: Configure server typechecking

**Files:**
- Create: `server/tsconfig.json`
- Modify: `server/package.json`

- [ ] **Step 1: Add server compiler configuration**

Create `server/tsconfig.json`:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022"],
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "allowJs": true,
    "checkJs": false,
    "strict": false,
    "noEmit": true,
    "skipLibCheck": true,
    "types": ["node"]
  },
  "include": ["src"],
  "exclude": ["node_modules"]
}
```

- [ ] **Step 2: Add server typecheck script**

Add this entry to `server/package.json` scripts:

```json
"typecheck": "tsc -p tsconfig.json"
```

Do not change existing server runtime or test scripts.

- [ ] **Step 3: Run server typecheck**

Run:

```bash
pnpm --filter wp-json-discovery-server run typecheck
```

Expected: TypeScript exits 0 without generating files or changing server runtime behavior.

### Task 4: Add the workspace typecheck entry point

**Files:**
- Modify: `package.json`

- [ ] **Step 1: Add root typecheck script**

Add this entry to the root `package.json` scripts:

```json
"typecheck": "pnpm --filter frontend run typecheck && pnpm --filter wp-json-discovery-server run typecheck"
```

The frontend check runs first; the server check runs only if it passes.

- [ ] **Step 2: Run the combined typecheck**

Run:

```bash

```

Expected: both workspace checks pass and no build artifacts appear.
